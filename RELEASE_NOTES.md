# MoreInfo 1.0.1 — 新版本适配与中英文界面

- 新增 Minecraft 1.26.52.3 精确适配，装备与状态显示、副手交互及连续操作均已通过单人世界和服务器真机测试。
- 新增游戏内语言设置，可在简体中文与英文之间即时切换，默认使用简体中文并保存选择。
- 设置页面、HUD 状态文字与装备提示会随语言同步切换；恢复默认会重新使用简体中文。
- 现支持 Minecraft 1.26.44.3、1.26.45.1、1.26.50.4 和 1.26.52.3（Android ARM64）。
- 未知或不匹配的游戏版本仍会安全停止加载对应功能，避免使用错误适配。

# MoreInfo 1.0.1 — New Version Support and English UI

- Adds exact Minecraft 1.26.52.3 compatibility, device-tested for the HUD, offhand interaction, and repeated operations in both single-player and multiplayer.
- Adds an in-game language setting for instant switching between Simplified Chinese and English. Simplified Chinese remains the default, and the selected language is saved.
- Settings, HUD status text, and equipment tooltips switch languages together; restoring defaults returns the interface to Simplified Chinese.
- Now supports Minecraft 1.26.44.3, 1.26.45.1, 1.26.50.4, and 1.26.52.3 on Android ARM64.
- Unknown or mismatched game builds continue to be rejected safely instead of using an incorrect compatibility profile.
